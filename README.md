# Kelime Bilgisi Testi

Metindeki İngilizce kelimeleri kendi bilgine göre işaretleyip kaç kelimeyi bildiğini ölçen, tarayıcıda çalışan tek dosyalık bir uygulama.

Bu proje Anthropic'in yapay zeka asistanı Claude ile geliştirilmiştir.

## Veri kaynakları
- Okunuş: CMU Pronouncing Dictionary
- Çeviri: FreeDict İngilizce-Türkçe sözlüğü (gtksozluk2, GPL)
